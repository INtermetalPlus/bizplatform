# Introduction

**How platform work 🤔?**

🔹01: Customer posting request to any products💻

🔹02: Suppliers place price offer💱

🔹03: Customer selecting suitable supplier✅

## 🧰 Our app stack

Our app has been build with nexts web-technologies: 

**Frontend**
- Frmework: [NEXTjs](https://www.npmjs.com/package/next)
- App frame & programming languages: HTML5, SCSS, module CSS, [TS](https://www.npmjs.com/package/typescript)/[TSX](https://www.npmjs.com/package/tsx)
- State manager: [Zustand](https://www.npmjs.com/package/zustand)
- Hooks creation lib: [Zustand](https://www.npmjs.com/package/zustand)
- Form validathion and similar libs: [React-hook-form](https://www.npmjs.com/package/react-hook-form), [validator.js](https://www.npmjs.com/package/validator)
- Auth libs: [NextAuth.js](https://www.npmjs.com/package/next-auth) (we using JWT tokens in our registration)
- Other libs: [AntDesign](https://www.npmjs.com/package/antd), [react-select](https://www.npmjs.com/package/react-select), [storybook](https://www.npmjs.com/package/storybook)
- Project configuration: [ESlint](https://www.npmjs.com/package/eslint), [Prettier](https://www.npmjs.com/package/prettier)
- Api managers: [Swagger](https://swagger.io/tools/swagger-ui/), [Postman](https://www.postman.com/),

**Backend**
- Framework: [MongoDB](https://www.mongodb.com/), [Django](https://www.djangoproject.com/)
- Api framework: [Fast API](https://fastapi.tiangolo.com/)
- Admin panel: [Jazzmin](https://django-jazzmin.readthedocs.io/#demo)
- Programming language: Python
